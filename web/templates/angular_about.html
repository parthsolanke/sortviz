About SortViz

SortViz is a sorting algorithm visualizer. It replays each swap the backend records so you can watch an array move toward its sorted order, one step at a time.

The server is written in Go and exposes a single POST /sort endpoint. This frontend is built with AngularJS and split into separate pages for the visualizer, the algorithm reference and this overview.

Eight algorithms are available: selection, bubble, insertion, merge, quick, heap, shell and cocktail shaker sort. Use the Controls panel to pick one, change the animation speed, or inspect its complexity and reference implementation.
